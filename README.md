**在线运行：** [Xu lab Mouse VPL TI Simulator v4](https://tivplsimulatorv4-dp7r8p99mgktdkfyjkmhyf.streamlit.app/)

Xu lab 的小鼠左侧 VPL 时间干涉刺激研究软件，提供 Allen CCF 解剖约束解析预览、四电极参数化布局、三维透明脑与电场节点、三正交切面，以及本地注册 EFMouse FEM 工作流。

默认靶点为相对 bregma 的 `AP = -1.94 mm, ML = -1.75 mm, DV = -3.10 mm`。云端版本用于交互式参数筛查；正式动物级结论仍需个体或经验证模板配准、完整 FEM、网格收敛和实验验证。

完整安装、坐标、电极、仿真与科学边界说明见 **[中文文档](README_CN.md)**。
