This software from the Xu Lab facilitates the study of Temporal Interference (TI) stimulation targeting the mouse left VPL thalamus. It features a preview based on Allen CCF anatomical constraints, a parametric four-electrode layout, a 3D transparent brain model with electric field nodes, views across three orthogonal planes, and a local EFMouse FEM registration workflow.

The default target coordinates relative to bregma are `AP = -1.94 mm, ML = -1.75 mm, DV = -3.10 mm`. The cloud-based version is intended for interactive parameter screening; definitive conclusions for animal studies require registration to individual brains or validated templates, full FEM analysis, mesh convergence checks, and experimental validation.

For details regarding full installation, coordinates, electrode configuration, simulation parameters, and scientific boundaries, please refer to the **[Chinese Documentation](README_CN.md)**.
